## 1. 产品

MacMarkDown 是一款面向 macOS 的原生 Markdown 编辑器，用纯 Swift 与 SwiftUI 从零写成。它面向作家、开发者与技术写作者，他们需要一款快速、本地优先、专注的写作工具，具备实时预览、深度格式化支持与一流的导出能力，且始终留在原生 macOS 之内。

macOS 26 与 Swift 6.4 为 Apple 的开发生态开启了新纪元：SwiftUI、Observation、TextKit 2 与 Swift 并发已经成熟到足以承载一个完整的写作工具。这正是 MacMarkDown 的基石：

- **TextKit 2** 提供按视口的布局能力，自定义编辑器只渲染长文档的可见区域，同时仍能提供精确的插入点、选区、行号与滚动锚点几何信息。
- **SwiftUI 与 Observation** 让应用以声明式方式组织窗口、设置与工具栏，并按属性追踪变化，使预览、状态栏与设置只在状态真正改变处更新。
- **Swift 6.4 严格并发** 让数据竞争安全成为编译期属性：编辑器状态由主 Actor 隔离，解析出的文档与格式化命令是不可变的 `Sendable` 值，边界由编译器强制校验。
- **原生文本输入**——包括日文、中文与韩文输入法——直接实现在编辑器的文本视图上，组字、候选窗口与按键绑定的行为与 macOS 用户的预期完全一致。

最终得到一款原生多窗口文档编辑器：文件保留在磁盘上，文档可从访达、`macmarkdown` 命令行工具或 `x-macmarkdown://` URL Scheme 打开；分栏布局把编辑器与预览并排摆放；主题、样式、模板与插件都可以从应用的数据目录扩展。

## 2. 目标架构

| 属性 | 值 |
|------|----|
| 语言 | Swift 6.4，开启严格并发 |
| 最低系统 | macOS 26（使用 macOS 27 SDK 构建） |
| UI 框架 | SwiftUI；AppKit 仅用于文本表面与 Web 块背后的轻量 `NSViewRepresentable` |
| 编辑器 | 自定义 TextKit 2 视图（`MarkdownTextView`）：`NSTextContentStorage` → 自定义布局管理器 → `NSTextContainer`，按视口布局并复用片段视图，支持输入法、选区、格式化、智能编辑与无障碍 |
| 预览 | 同一个 TextKit 2 表面的只读实例；表格与 MathJax 公式隔离在按块创建的 `WKWebView` 中；代码语法高亮为原生实现 |
| Markdown 解析 | `swift-markdown`（Apple）生成文档树；同一棵解析树同时供预览、导出与滚动锚点使用 |
| Front matter | `Yams` |
| 状态管理 | Observation（`@Observable`、`@MainActor`）；`Preferences` 由 `UserDefaults` 支撑 |
| 设置 | SwiftUI `Settings` 场景，五个面板：通用、Markdown、编辑器、HTML、终端 |
| 文档模型 | `MarkdownDocument` 持有文本、front matter 与修改状态；会话注册表为每个文档分配独立窗口；可选的防抖自动保存 |
| 导出 | AST → HTML 渲染器；HTML、PDF（打印管线）、打印、复制 HTML |
| 滚动同步 | 基于锚点的 `ScrollSyncService`；默认为编辑器 → 预览，可选双向模式 |
| CLI | `macmarkdown` 伴生工具（位于 `/usr/local/bin`），可从「设置 ▸ 终端」安装 |
| URL Scheme | `x-macmarkdown://open?url=…` |
| 脚本 | 通过随附的 `MacMarkDown.sdef` 支持 AppleScript（`text` 可读写，`html` 只读） |
| 插件 | 位于 `~/Library/Application Support/MacMarkDown/PlugIns`、实现 `MacMarkDownPlugIn` 的插件包 |
| 外观资源 | 编辑器主题（`*.style`）、预览样式（`*.css`）、HTML 模板 |
| Bundle ID | `com.xaiat.MacMarkDown` |
| 本地化 | 21 种语言，包括简体中文（`zh-Hans`）与繁体中文（`zh-Hant`） |

## 3. 功能范围

### 3.1 编辑

- 自定义 TextKit 2 编辑器：快速的按视口布局、平滑滚动、长文档中的 O(1) 跳转、自动换行、允许滚动越过文末。
- 分屏编辑器 + 实时预览；编辑器可置于左侧或右侧；面板可调整大小；可选最大文本宽度。
- 格式化工具栏与「格式」菜单：段落与 H1–H6、粗体、斜体、内联代码、删除线、下划线、高亮、注释、无序/有序列表、引用块、代码块、链接、图片、缩进/取消缩进、新段落。
- 智能编辑，每项行为均可单独配置：ASCII 括号/引号与中日韩标点的配对补全、选区包裹、配对字符删除、回车时延续列表/引用块/缩进行、有序列表自动递增、Tab 转空格、选中行缩进/取消缩进、智能 Home。
- 实时语法高亮，编辑器主题可选。
- 行号栏、不可见字符显示、拼写检查、朗读（选区或整篇文档）、服务菜单、查找替换。
- 状态栏字数统计（词数、字符数或不含空格的字符数）。
- 拖放：文本插入到放置位置，拖入的图片文件以内联 base64 Markdown 插入，拖入的文档在应用中打开。
- 撤销/重做覆盖打字、格式化命令、查找替换与拖放；打开或还原文档会干净地重置历史。
- 通过标准 macOS 按键绑定实现完整键盘导航，并支持中日韩输入法组字。

### 3.2 Markdown 支持

- 基于 `swift-markdown` 的解析器，同一棵解析树同时供预览、HTML 导出与滚动锚点使用。
- 扩展开关：词内强调、表格、围栏代码块、自动链接、删除线、下划线、高亮、上标、脚注、引用块与 SmartyPants；以及手动渲染模式，供作者自行决定何时渲染。
- YAML front matter 检测（用 Yams 解析），可选择在预览中隐藏。
- TeX 数学公式（围栏与行内 `$…$`）、Mermaid 图表与 Graphviz 图表。
- 渲染输出中的任务列表、硬换行、目录生成、脚注、代码块附属信息与行号。

### 3.3 预览与渲染

- 对解析后文档的实时原生预览，使用同一个 TextKit 2 表面，支持可选文本与整篇复制。
- 同步滚动：默认编辑器 → 预览，并提供可选双向模式；密集的块/列表项锚点让两个面板保持同步。
- 表格与 MathJax 公式在隔离的按块 Web 视图中渲染，并把自身高度上报给布局；Mermaid 与 Graphviz 图表在导出的 HTML 中渲染。
- 原生代码语法高亮，调色板可选。
- front matter 隐藏、目录渲染、预览字体策略（跟随编辑器/系统/自定义）以及相对基础字号的缩放。
- 链接处理：打开已有目标、创建缺失文件，由偏好设置控制。

### 3.4 导出与打印

- 导出 HTML，可选内嵌样式与代码高亮。
- 通过打印管线导出 PDF；打印。
- 复制渲染后的 HTML 到剪贴板。

### 3.5 偏好设置

五个面板，全部存储在 `UserDefaults` 中并通过 `Preferences` 观察：

- **通用**——启动行为、更新偏好（包括预发布通道）、链接目标创建。
- **Markdown**——手动渲染、扩展开关。
- **编辑器**——字体与字号、主题、布局（宽度限制、编辑器位置、行距、内边距）、行为（字数统计及类型、同步滚动、双向同步、智能 Home、制表符转换、前缀插入、自动递增、配对补全、列表标记、允许滚动越过文末、文件末尾换行、自动保存、拼写检查、行号、不可见字符）。
- **HTML**——样式表、模板、可选文本预览、front matter、任务列表、硬换行、目录、语法高亮及调色板、行号、代码块附属信息、MathJax 与行内数学、Mermaid、Graphviz、预览字体、缩放、相对链接的默认目录。
- **终端**——安装或移除 `macmarkdown` 命令行工具。

### 3.6 可扩展性与自动化

- 应用 `PlugIns` 目录中实现 `MacMarkDownPlugIn` 协议的插件包，以菜单命令形式呈现。
- 通过随附的脚本定义支持 AppleScript：聚焦文档的 `text`（可读写）与 `html`（只读），以及标准套件。
- `x-macmarkdown://open?url=…` URL Scheme，供其他应用与工具调用。
- `macmarkdown` CLI：在应用下次启动时打开文件，或把通过管道传入的标准输入读入新文档。
- 21 种语言的本地化（`.xcstrings`），包括简体中文与繁体中文。

## 4. 路线图 — 5 个阶段

| 阶段 | 名称 | 范围 | 退出标准 |
|------|------|------|---------|
| 1 | 基础 | 工程脚手架、应用/窗口/文档模型、分屏 `DocumentView`、编辑器与预览表面、基础解析 → 渲染、打开/保存/自动保存 | 能打开一个 Markdown 文件、编辑、保存，并看到实时预览 |
| 2 | 渲染 | 完整渲染管线（RFC-002）、扩展开关、主题/样式/模板、MathJax/Mermaid/Graphviz 块、导出 | 每个受支持的 Markdown 扩展与块类型都有渲染测试覆盖，且预览与 HTML 导出基于同一棵解析树、结果一致 |
| 3 | 编辑器 | TextKit 2 表面：视口布局、选区、输入法、撤销、标准编辑命令、无障碍、行号栏、不可见字符 | 编辑器通过其行为测试套件（编辑、输入法、选区、无障碍），并在万行以上文档中保持流畅 |
| 4 | 进阶 | 格式化工具栏与命令、智能编辑、语法高亮、字数统计、查找替换、拖放、滚动同步、导出界面、设置面板 | 完整的日常编辑工作流可用，且每条格式化命令与每项智能编辑行为都有单元测试 |
| 5 | 打磨 | CLI、URL Scheme、AppleScript、插件、21 种语言本地化、性能专项、文档 | 应用已准备好作为主力 Markdown 编辑器投入日常使用 |

每个阶段都在其自身的验收测试与既定标准通过后结束。

## 5. 范围与成功标准

- **范围内**：一款用于写作与阅读 Markdown 的原生 macOS 应用——分屏编辑器与实时预览、上述格式化与智能编辑能力、导出、设置、自动化与本地化。
- **首个版本不包含**：macOS 以外的平台、云账号或同步服务、实时协作，以及托管式插件市场。
- **成功标准**：
  - 「功能范围」中列出的每项功能都已实现并有自动化测试覆盖。
  - 每个受支持的 Markdown 扩展与块类型都有解析与渲染测试覆盖。
  - 应用在 Swift 6.4 严格并发下零警告构建。
  - 编辑保持流畅：常见文档的打字延迟保持平稳，万行以上文档仍然可用。
  - 畸形 Markdown 优雅降级；大文档不会导致应用崩溃。
  - 21 种语言的本地化全部完成，包括简体中文与繁体中文。

## 6. 风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 快速编辑时 TextKit 2 视口或布局出现回归 | 高 | 在 `MarkdownTextViewTests` 中以无头方式驱动真实视口管线；实时滚动与缩放期间推迟内容测量（RFC-003） |
| 自定义文本视图中的输入法组字边界情况 | 高 | 暂存文本处理实现在 `MarkdownTextView+InputClient` 中并有测试覆盖；配对补全跳过暂存范围；发布 QA 包含中日韩输入法检查 |
| `swift-markdown` 不覆盖应用特有扩展（脚注、下划线、高亮、上标、引用块） | 中 | 扩展以实现为保持行号的解析改写；每个扩展都有解析与渲染测试；解析器是预览、导出与锚点的唯一入口 |
| 编辑器与预览之间的滚动同步漂移 | 中 | 两个面板消费同一棵解析树生成的同一份有序锚点表；`ScrollSyncService` 有单元测试，双向模式使用精确逆映射以避免互相反馈 |
| 主题、样式或模板格式回归 | 低 | 文件格式由本项目的主题/样式读取器解析，并有固定样本测试覆盖 |
| AppKit 回调带来的严格并发摩擦 | 中 | `@MainActor` 隔离、遵循 SE-0466 的 AppKit 协议隔离实现，以及 Actor 边界上的 `Sendable` 值类型（RFC-001、RFC-003） |
