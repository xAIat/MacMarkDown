# Contributing to MacMarkDown

MacMarkDown is open source and is a volunteer effort. This means that it depends on people to give some of their free time to improve it and make it even better.

If you are reading this, then you are probably curious or want to contribute in some way. Read on to see how you can do so.

## Getting the Source Code

MacMarkDown is hosted on GitHub:

https://github.com/xAIat/MacMarkDown

Here you can get the source code, read through the issues and start contributing.

## But, I am not a Coder

Contribution is not limited to software developers, since there are other ways you can help. For example, contributing towards documentation, translation and support. Open an issue on GitHub to see how you can help.

## Joining the Conversation

If you are new to the project, then a good place to start is the issue tracker:

https://github.com/xAIat/MacMarkDown/issues

Introduce yourself and find out how you can help out.
